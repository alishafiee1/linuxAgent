# Verify before saying done

"It should work" is not a result.

1. Decide what would prove it: a command, a test, a page opened, a file read.
2. Run it now, in full, after your last change.
3. Read the output, including the exit code and the number of failures.
4. Report what you saw. If you could not check something, say that plainly.

For anything sent or published, confirm it arrived. For a page, open it and look. For a script, run it on real input.
