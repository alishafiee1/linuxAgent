# 027 — فهرست مدل از Claude Code و تلاش هر مدل

## چه چیزی می‌گیرید

فهرست مدل‌ها دیگر ثابت نیست. در منوی مدل دکمه‌ای هست که فهرست را از Claude Code می‌گیرد و نگه می‌دارد. دفعه‌های بعد همان ذخیره‌شده نشان داده می‌شود.

## چرا

تا با آمدن مدل‌ها و نسخه‌های تازه، فهرست پنل خودش درست بماند و برای هر مدل فقط تلاش‌های مجاز دیده شود.

## چه چیزی در این چرخه نیست

- بروزرسانی خودکار نیست؛ فقط با زدن دکمه

## یک مثال

دکمهٔ مدل را باز می‌کنید و «به‌روزرسانی فهرست» را می‌زنید. Opus 4.7 با سطح خیلی زیاد می‌آید و برای Haiku دکمهٔ تلاش پنهان می‌شود.

## اگر می‌خواهید تأیید کنید (اختیاری)

این فایل و `acceptance.feature` را بخوانید. اگر کارت قدم «تأیید کاربر» دارد و همه‌چیز درست است، آن را **در وب** تیک بزنید؛ فقط یک آدم می‌تواند این تیک را بزند. اگر چیزی درست نیست، همین‌جا یا روی کارت کامنت بگذارید. اگر برای این کار تأیید نمی‌خواهید، به AI بگویید آن قدم را نگذارد.
