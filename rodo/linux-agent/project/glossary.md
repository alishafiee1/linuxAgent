# واژه‌نامه

> هر واژه در همهٔ سناریوها و spec ها همان معنایی را دارد که اینجا نوشته شده است.

| واژه | معنی | در کد |
|---|---|---|
| بات | یک دستیار با اسم، شخصیت، پوشه و تنظیمات خودش | `Bot` |
| گفت‌وگو | یک رشته پیام با یک بات که حافظهٔ session را ادامه می‌دهد | `Conversation` |
| اجرا | یک بار کار کردن موتور برای یک پیام | `Run` |
| موتور | برنامه‌ای که کار را واقعاً انجام می‌دهد. اول Claude Agent SDK است و بعدها موتورهای دیگر هم اضافه می‌شوند. | `Engine` |
| تأیید | اجازه‌ای که پیش از یک کار حساس از مسعود گرفته می‌شود | `Approval` |
| هماهنگ‌کننده | بخشی از سرور که اجراها را در صف می‌گذارد، شروع می‌کند و پیگیری می‌کند | `Orchestrator` |
| روتین | کاری که در زمان مشخص خودکار تکرار می‌شود | `Routine` |
| مهارت | روش ذخیره‌شدهٔ انجام یک کار که همهٔ بات‌ها از آن استفاده می‌کنند | `Skill` |
| گاوصندوق | جای رمزنگاری‌شدهٔ رمزها و اطلاعات حساس، بیرون از دسترس بات‌ها | `Vault` |
| سقف اشتراک | محدودیت استفادهٔ اشتراک Claude در یک بازهٔ زمانی | `usage limit` |
