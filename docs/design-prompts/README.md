# پرامپت‌های طراحی هر صفحه

هر فایل یک پرامپت کامل و مستقل است. فایل را باز کن، همهٔ متن را کپی کن، به ابزار طراحی بده و عکس همان صفحه را هم پیوست کن.

ترتیب پیشنهادی: اول `01-chat` را طراحی کن و خروجی را قبول کن. بعد جدول رنگ و فاصله‌هایی که از آن گرفتی را به ابتدای پرامپت بقیهٔ صفحه‌ها اضافه کن تا همه شبیه هم بمانند.
