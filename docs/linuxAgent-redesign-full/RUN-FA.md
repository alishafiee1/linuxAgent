# راهنمای اجرا (نسخه‌ی نمایشی)

## پیش‌نیاز
- فقط **Node.js نسخه ۱۸ یا بالاتر** لازم است. هیچ `npm install`ی لازم نیست؛ نسخه‌ی ساخته‌شده‌ی برنامه (dist) همراه بسته است.

## اجرا در ۳ قدم

```bash
# ۱) بسته را باز کنید و وارد پوشه شوید
cd linuxAgent-redesign-full        # یا هر نامی که موقع باز کردن داشت

# ۲) سرور نمایشی را اجرا کنید
node mock-server-demo/mock-server.mjs

# ۳) در مرورگر باز کنید
http://127.0.0.1:8787
```

## ورود به برنامه
- نام کاربری: هر چیزی (مثلاً `demo`)
- رمز عبور: هر چیزی
- کد تأیید ۶ رقمی: هر ۶ رقم (مثلاً `123456`)

## چیزهایی که باید ببینید
- **تعویض تم روشن/تاریک**: دکمه در نوار بالای صفحه
- **تعویض زبان فارسی/انگلیسی**: با تغییر جهت راست‌به‌چپ و چپ‌به‌راست
- **کارت تأیید ابزار**: در صفحه «تأییدها» — طراحی برجسته با دکمه‌های اجازه/رد
- **حالت موبایل**: عرض مرورگر را زیر ۷۶۸ پیکسل ببرید تا منوی همبرگری فعال شود
- **پنل کنار چت**: روی هر گفتگو کلیک کنید؛ وضعیت اجراها با رنگ و آیکون نشان داده می‌شود

## اگر خواستید سورس را ویرایش و دوباره بسازید
```bash
npm install            # فقط یک بار، در ریشه‌ی پروژه
npm run build          # ساخت مجدد dist
npm run typecheck      # بررسی تایپ‌ها
```

## نکته
این سرور یک بک‌اند نمایشی (Mock) است — داده‌ها واقعی نیستند و با ری‌استارت سرور به حالت اول برمی‌گردند. هدف فقط دیدن طرح جدید رابط کاربری است.
